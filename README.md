# Hi 👋 I'm Cong Le

Mobile Lead at Capital One, based in the UK. I'm a relaxed, curious developer who enjoys creating intuitive mobile experiences and solving complex technical challenges.

Alongside my day job, I build apps and games through **Pocket Grove Ltd** — from everyday tools to sports career simulators, with native iOS and Android experiences and the services behind them.

🌐 **My app portfolio: [pocketgrove.com](https://pocketgrove.com/?utm_source=github&utm_medium=referral&utm_campaign=profile_portfolio)** — apps, games, and a [blog](https://pocketgrove.com/blog/) on building them.

Try [Anniversary Tracker](https://pocketgrove.com/apps/anniversary-tracker/) if you want a simple way to keep meaningful dates, milestones, and reminders together — available on **iPhone and Android**.

For a player-career football game, try [Football Career Quest](https://pocketgrove.com/apps/football-career-quest/) — train, play, move clubs, and build your career.

For a basketball career simulator, try [Hoop Quest](https://pocketgrove.com/hoop-quest/) — from backyard prospect to all-time legend.
